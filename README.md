# 📘 Python Notes App

A simple Python program that allows users to add and view notes using file handling.

## 🚀 Features
- Add new notes
- View saved notes
- Stores notes in a text file
- Simple command-line interface
- Beginner-friendly project

## 🛠 Built With
- Python

## ▶️ How to Run

1. Download or clone the repository  
2. Open the project folder  
3. Run the program  

python notes_app.py
